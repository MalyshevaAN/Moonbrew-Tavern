# Moonbrew Tavern

**Moonbrew Tavern** — мобильная игра для Android в жанре уютной сюжетной RPG с управлением таверной. Игрок становится владельцем старой магической таверны на краю цивилизации: принимает необычных посетителей, готовит напитки, развивает заведение и постепенно раскрывает истории персонажей и мира.

Проект разрабатывается как компактная, но цельная инди-игра с упором на атмосферу, диалоги, отношения с персонажами и постепенное развитие таверны.

## Идея проекта

Каждую ночь в таверну приходят разные гости: ведьмы, алхимики, странствующие рыцари, призраки, охотники и другие жители магического мира. У каждого персонажа есть характер, предпочтения, отношение к игроку и собственная история.

Игровой процесс строится вокруг повторяющегося цикла:

1. Подготовка таверны.
2. Приём посетителей.
3. Диалоги и выбор реплик.
4. Приготовление магических напитков.
5. Получение наград.
6. Улучшение таверны.
7. Открытие новых рецептов, событий и сюжетных линий.

## Основные особенности

- Уютная фэнтезийная атмосфера.
- Одна основная локация, которая постепенно меняется.
- Система посетителей с отношениями и личными историями.
- Приготовление напитков из ингредиентов.
- Развитие таверны через улучшения.
- Случайные события во время игровых ночей.
- Постепенное открытие рецептов, персонажей и фрагментов мира.

## Платформа

- Платформа: **Android**.
- Язык разработки: **Kotlin**.
- Основная среда разработки: **Android Studio**.

## Выбранные инструменты

| Задача | Инструмент |
| --- | --- |
| Разработка под Android | Android Studio |
| Язык | Kotlin |
| Графический фреймворк | Android Canvas / Skia |
| Физический модуль | Box2D |
| Сборка проекта | Gradle |
| Версионирование | Git + GitHub |
| Архитектурные схемы | UML / Mermaid |

Android Canvas / Skia выбран для отрисовки 2D-сцены, интерфейса и визуальных эффектов. Box2D можно использовать как физический модуль для небольших интерактивных элементов и мини-игры приготовления напитков.
