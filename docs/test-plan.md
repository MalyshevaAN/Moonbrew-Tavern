# План тестирования

## Цель

Проверить, что текущий прототип Moonbrew Tavern стабильно проходит основной игровой цикл, корректно сохраняет прогресс и не ломает переходы между фазами ночи.

## Область тестирования

- Android-приложение `android-app/app`
- Игровая логика в `DefaultDataRepository`
- Навигация между фазами `Entrance -> Tavern -> Dialogue -> RecipeBook -> Brewing -> Result -> Summary`
- Локальное сохранение прогресса через `Jetpack DataStore`
- Базовые UI-проверки для существующих экранов

## Что проверяем

### 1. Бизнес-логика

- формирование и обработку очереди посетителей;
- покупку рецептов и ингредиентов;
- списание золота и ингредиентов;
- оценку напитка при точном и частичном совпадении;
- обработку нехватки ингредиентов;
- завершение ночи и переход к следующей;
- глобальный таймер ночи при переходах между экранами;
- восстановление игры из сохраненного snapshot.

### 2. UI и навигацию

- отображение базовых экранов без падения;
- наличие ключевых текстов и элементов интерфейса;
- корректное открытие итогового экрана ночи;
- отсутствие тупикового состояния при пустой очереди и отсутствии гостей.

### 3. Сохранение прогресса

- сохранение игрового состояния после изменений;
- восстановление номера ночи, золота, репутации, рецептов и текущей фазы;
- устойчивость к пограничным и неполным сохранениям.

## Уровни тестирования

### Модульные тесты

Покрывают игровую логику репозитория и ViewModel.

Текущие файлы:

- `android-app/app/src/test/java/com/example/moonbrewtavern/data/DefaultDataRepositoryTest.kt`
- `android-app/app/src/test/java/com/example/moonbrewtavern/ui/main/MainScreenViewModelTest.kt`

### Инструментальные UI-тесты

Покрывают базовую проверку экрана в Android-окружении.

Текущий файл:

- `android-app/app/src/androidTest/java/com/example/moonbrewtavern/ui/main/MainScreenTest.kt`

### Ручное тестирование

Нужно для сценариев, которые сложно полноценно закрыть unit-тестами:

- полный игровой цикл одной ночи;
- переходы между экранами на эмуляторе;
- поведение после перезапуска приложения;
- визуальная проверка экрана конца ночи;
- стабильность UI в landscape-режиме.

## Команды запуска

### Модульные тесты

```bash
cd android-app
./gradlew testDebugUnitTest
```

### Инструментальные тесты

```bash
cd android-app
./gradlew connectedAndroidTest
```

### Полная локальная проверка перед релизом

```bash
cd android-app
./gradlew --no-daemon lintDebug testDebugUnitTest assembleDebug
```

## Критерии готовности

Сборка считается приемлемой для релиза, если:

- проходят `lintDebug`, `testDebugUnitTest` и `assembleDebug`;
- не остается известных dead-end сценариев в основном игровом цикле;
- экран конца ночи открывается корректно;
- прогресс сохраняется и восстанавливается после перезапуска;
- ручной прогон полной ночи не выявляет критических ошибок.
