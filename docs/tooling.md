# Инструментарий

## Основная экосистема

Проект остаётся в экосистеме **Android**. Это удобно для учебной демонстрации, сборки APK и запуска на эмуляторе или реальном устройстве.

Основная среда разработки:

- **Android Studio** — IDE для Android-проектов.
- **Android Emulator** — запуск игры без физического устройства.
- **Gradle** — сборка проекта.

## Выбранный стек

| Область | Инструмент | Зачем нужен |
| --- | --- | --- |
| Платформа | Android | Целевая мобильная платформа. |
| Язык | Kotlin | Современный основной язык Android-разработки. |
| Графика | Android Canvas / Skia | Отрисовка 2D-сцены, персонажей, интерфейсных элементов и эффектов. |
| Физика | Box2D | Простая физика для интерактивных объектов и мини-игр. |
| Сборка | Gradle | Управление проектом и зависимостями. |

## Почему Android Canvas / Skia

Android Canvas работает поверх графической библиотеки Skia и подходит для собственной 2D-отрисовки без использования полноценного игрового движка.

Для Moonbrew Tavern этого достаточно, потому что игра строится вокруг одной основной сцены таверны, интерфейса, персонажей, анимаций света, дыма, дождя и магических эффектов.

## Почему можно оставить Box2D

Box2D относится к физическим движкам, а по требованиям проекта графические и физические движки использовать можно. В проекте он нужен не для всей игры, а для отдельных интерактивных элементов:

- движение ингредиентов в мини-игре;
- столкновения небольших объектов;
- простые физические эффекты капель, пузырьков или частиц.
