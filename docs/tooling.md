# Инструментарий

## Основная экосистема

Проект остаётся в экосистеме **Android**. Это удобно для учебной демонстрации, сборки APK и запуска на эмуляторе или реальном устройстве.

Основные инструменты разработки:

- **Android Studio** — основная IDE для Android-проектов.
- **Gradle** — сборка проекта и управление зависимостями.
- **Android Emulator / Android CLI** — запуск приложения без физического устройства.

## Почему Jetpack Compose

Jetpack Compose подходит для текущего формата проекта, потому что Moonbrew Tavern строится вокруг экранов, состояний, переходов и реактивного обновления интерфейса.

Для Moonbrew Tavern это даёт:

- быстрый прототип экранов и игровых сцен;
- простую связку с `StateFlow` и доменными моделями;
- удобное развитие UI без перехода на полноценный игровой движок.

## Почему Jetpack DataStore

Для текущего проекта нужен не набор сложных таблиц, а один компактный слепок игрового прогресса: день, золото, репутация, открытые рецепты, ингредиенты, отношения с NPC и состояние текущей ночи.

`Jetpack DataStore` выбран потому что:

- он лучше подходит для небольшого локального состояния, чем полноценная база данных;
- он современнее и безопаснее по работе с данными, чем `SharedPreferences`;
- его достаточно для одного игрового save snapshot без лишней сложности `Room`.

## Почему текущая тестовая стратегия именно такая

Для этого прототипа основной риск находится не в сложном backend или сетевом взаимодействии, а в логике игрового состояния:

- переходах между фазами ночи;
- сохранении и восстановлении snapshot;
- расчете результата напитка;
- устойчивости навигации и таймера.

Поэтому основа автоматизации здесь — unit-тесты для `DefaultDataRepository`, а UI-тесты используются как дополнительная проверка того, что ключевые экраны вообще отображаются в Android-среде.
