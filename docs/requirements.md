# Требования

## Требования задания

| Требование | Решение в проекте |
| --- | --- |
| Мобильная игра | Игра разрабатывается под Android. |
| Жанр | Cozy narrative RPG |
| Язык | Kotlin. |
| Можно использовать графические и физические движки | В текущей реализации отдельные графические и физические движки не требуются: интерфейс и игровые сцены собраны на Android UI-стеке. |
| Игровые движки использовать нельзя | Unity, Godot, Unreal и похожие игровые движки не используются. |
| Контент должен быть оригинальным | Мир, персонажи, рецепты, события и таверна создаются специально для проекта. |


## Функциональные требования

Игра должна позволять игроку:

- управлять таверной;
- принимать посетителей;
- вести диалоги;
- готовить напитки из ингредиентов;
- получать награды;
- улучшать таверну;
- открывать новые рецепты, события и персонажей;
- сохранять прогресс.

## Нефункциональные требования

- Игра должна запускаться на Android.
- Управление должно быть удобным для мобильного устройства.
- Архитектура должна позволять расширять контент.
- Основные игровые системы должны быть отделены друг от друга.
- Визуальный стиль должен поддерживать уютную фэнтезийную атмосферу.
- Проект не должен зависеть от полноценного игрового движка.

## Технические ограничения

- Минимальная версия Android: Android 7.0 / API 24.
- Игра должна работать **офлайн** (контент внутри приложения).
- Сохранение прогресса должно переживать перезапуск приложения.
- Локальное сохранение прогресса реализуется через `Jetpack DataStore`.
