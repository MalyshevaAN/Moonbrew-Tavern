# Contributing

Спасибо за вклад в Moonbrew Tavern!

## Базовый процесс

- Любая работа начинается с GitHub Issue.
- Изменения в код/документацию вносятся через Pull Request.
- В `main` не пушим напрямую.

## Ветки

- `feature/...` — новая функциональность
- `fix/...` — исправления
- `content/...` — контент (диалоги/рецепты/события)
- `docs/...` — документация

## Правила PR

- PR должен решать одну задачу.
- В описании: что сделано, как проверить, что изменилось для игрока.
- Минимум один ревьюер (если команда позволяет).

## Definition of Done

- Проект собирается и запускается (для кода).
- Документация обновлена (если менялись правила/архитектура).
- Для контента: добавлены данные и короткое описание сценария/триггеров.
